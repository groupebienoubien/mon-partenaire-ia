# Mon Partenaire IA · Maquette

Maquette cliquable d'un partenaire IA opérationnel pour les TPE et indépendants.
Site statique (HTML/CSS/JS, sans dépendance), pensé pour mobile et PC.

## Contenu

- **Vitrine** : promesse, situations concrètes scénarisées (carrousel), démonstration de l'apprentissage (découverte de l'entreprise, corrections retenues), réglage de l'autonomie par tâche.
- **Brainstorming (lot 2)** : échange scénarisé et interactif qui aide le dirigeant à trouver son premier cas d'usage et produit une fiche de cas d'usage.

Les entreprises, scénarios et chiffres sont illustratifs. Aucune donnée n'est collectée.

## Lancer en local

Ouvrir `vitrine/index.html` dans un navigateur.

Liens directs utiles :

- `vitrine/index.html#brainstorm` : ouvre directement le brainstorming
- `vitrine/index.html#cas-relances-devis` : ouvre un cas d'usage précis

## Modifier les contenus

- `vitrine/js/data.js` : personas, cas d'usage et leurs scénarios, démonstration d'apprentissage
- `vitrine/js/brainstorm-data.js` : script du brainstorming et règles de la fiche de cas d'usage
